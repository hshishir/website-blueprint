# Quality Checklist

## Content

- [ ] Sample company name removed
- [ ] Sample email removed
- [ ] All `TODO:` markers resolved or intentionally retained
- [ ] No fabricated claims
- [ ] Calls to action work
- [ ] Company description is consistent
- [ ] Services are distinct and outcome-oriented

## Design

- [ ] Theme matches approved tokens
- [ ] Section hierarchy is clear
- [ ] Mobile layout is usable
- [ ] No horizontal overflow
- [ ] Cards remain readable
- [ ] CTA stands out without overwhelming the page

## Animation

- [ ] Entrance animations occur once
- [ ] Hover movement is subtle
- [ ] Continuous motion is limited
- [ ] Reduced-motion preference is respected
- [ ] Animation does not delay access to content

## Accessibility

- [ ] One `h1`
- [ ] Heading levels are logical
- [ ] Navigation works by keyboard
- [ ] Focus indicators are visible
- [ ] Links are descriptive
- [ ] Color contrast is sufficient
- [ ] Images have appropriate alt text

## Technical

- [ ] `npm run lint`
- [ ] `npm run typecheck`
- [ ] `npm run build`
- [ ] No console errors
- [ ] No broken internal links
- [ ] GitHub Pages workflow succeeds
- [ ] Metadata is correct
- [ ] Favicon and social preview are present
