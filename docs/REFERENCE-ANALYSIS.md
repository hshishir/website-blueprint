# Reference Analysis

## ks-site patterns adopted

- Next.js marketing-site structure
- Section-based landing page
- Dark coal and charcoal surfaces
- Electric lime primary accent
- Cyan secondary accent
- Framer Motion for entrances, reveals, hover, and floating cards
- Static export and GitHub Pages deployment
- Markdown support
- Strict TypeScript

## flowbit patterns adopted

- Centralized motion variants
- Standard `initial`, `enter`, and `exit` animation states
- Reusable stagger, card, slide, scale, and page patterns
- Explicit reduced-motion handling
- Clear repository-level Claude Code instructions

## Patterns intentionally excluded

- Product-specific copy and branding
- FlowBit application state and mock enterprise data
- Workflow-studio application features
- KloudStak-specific claims and content
- Any customer-specific assets
