# Start Here

## Test the sample website

```bash
npm install
npm run dev
```

Visit `http://localhost:3000`.

## Create a real site

1. Copy this blueprint into a new GitHub repo.
2. Complete `docs/CONTENT-QUESTIONNAIRE.md`.
3. Replace sample values in `config/site.ts`.
4. Replace the Markdown files in `content/`.
5. Add logo and favicon assets to `public/`.
6. Paste `prompts/01-validate-inputs.md` into Claude Code.
7. Resolve blocking content gaps.
8. Paste `prompts/02-build-website.md` into Claude Code.
9. Review locally.
10. Paste `prompts/03-review-website.md`.
11. Paste `prompts/06-prepare-release.md`.
12. Push to `main` and enable GitHub Pages.
