# Claude Code Prompt: Refine Without Redesigning

Improve the website's visual polish while preserving:

- Existing information architecture
- Approved color tokens
- Centralized motion system
- Markdown content model
- Static export
- Accessibility behavior

Focus on spacing, hierarchy, responsive layout, card consistency, CTA visibility, and subtle motion.

Do not introduce a new theme, component framework, animation library, or decorative color palette.

Run lint, type checking, and build after changes.
