# Claude Code Prompt: Review the Website

Review the current website without performing a wholesale redesign.

Evaluate:

- Positioning clarity
- Business-value emphasis
- Section order
- CTA placement
- Repetition
- Typography hierarchy
- Theme consistency
- Animation consistency
- Mobile responsiveness
- Keyboard navigation
- Reduced-motion behavior
- SEO metadata
- Static export compatibility
- Performance risks

Produce:

1. Critical findings
2. High-value improvements
3. Optional polish
4. Exact files affected

Implement only critical findings and low-risk high-value improvements.

Run lint, type checking, and production build afterward.
